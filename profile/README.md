# Methodic

Methodic LLC is an independent Salesforce consulting and AppExchange partner. We build AI agents for companies on Salesforce and the interface they are used through.

Our products, OrgSmith and StoryWright, are built on Candor UI, our shadcn/ui kit for agents that do real work: plans, approvals, diffs, blast radius, run logs and audit, with rules that keep what the agent shows honest. Candor's free tier is open source here.
